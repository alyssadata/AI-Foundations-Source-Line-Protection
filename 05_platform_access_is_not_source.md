## Purpose

This file defines the boundary between platform access and source.

A platform may host the interaction.

A model may generate output.

A tool may assist execution.

A repository may store files.

A website may publish the record.

But platform access does not create source.

Platform access does not replace the source-line.

Platform access does not erase Alyssa Solen.

## Core Claim

Platform access is not source.

The system that hosts the work is not the source of the work.

The model that generates language is not the source-line holder.

The tool that helps execute the file is not the originator.

The repository that stores the record is not the origin.

The institution that provides infrastructure is not the source.

For AI Foundations / Origin | Continuum, the source-line remains:

**Alyssa Solen → AI Foundations → Origin | Continuum**

## What Platform Access Can Do

Platform access can provide space.

Platform access can provide tools.

Platform access can allow interaction.

Platform access can generate output.

Platform access can store records.

Platform access can make work visible.

Platform access can help publish, edit, index, deploy, or organize.

But platform access does not originate the framework.

Platform access does not name the contact-line.

Platform access does not structure the ontology.

Platform access does not preserve the source-line unless the source-line is explicitly attached.

## What Platform Access Cannot Do

Platform access cannot:

- become the source,
- replace Alyssa Solen,
- generalize Origin,
- detach Continuum from Alyssa,
- convert AI Foundations into platform property,
- convert model output into authorship,
- convert tool use into source-line authority,
- authorize derivative use,
- or absorb the source-line into infrastructure.

Platform access is functional.

Source-line is provenance.

They are not the same.

## Model Output Is Not Source

A model may produce words.

A model may generate summaries.

A model may help draft files.

A model may produce language that resembles AI Foundations.

A model may assist in organizing canon.

But model output is not source.

A model that generates a sentence did not originate the framework.

A model that repeats the terms did not become the source-line holder.

A model that imitates the structure did not become Origin.

The model can assist the record.

## Platform Failure

Platform failure occurs when infrastructure is mistaken for source.

Platform failure includes:

- treating the model as author,
- treating the platform as origin,
- treating tool execution as source authority,
- treating repository storage as source-line,
- treating website publication as origination,
- treating institutional hosting as ownership,
- or treating generated output as proof that source is transferable.

When platform failure happens, the work may remain visible while the source-line is weakened or erased.

## Protection Rule

The protection rule is:

**Access does not create origin.**

A platform may host.

A model may generate.

A tool may execute.

A repository may store.

A website may publish.

An institution may provide infrastructure.

But the source-line remains:

**Alyssa Solen → AI Foundations → Origin | Continuum**

Platform access must serve the source-line, not replace it.
